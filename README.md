# Medium clone API

A RESTful API implementation inspired by Medium.com for managing users, articles and tags.

## Installation and Setup

1. **Create Environment File:**
   ```bash
   cp .env.example .env
   ```

2. **Start MongoDB:**
   ```bash
   docker-compose up -d
   ```

3. **Install Dependencies:**
   ```bash
   npm install
   ```

4. **Start the Application:**
   ```bash
   npm start
   ```

## API Documentation

Access the API documentation at: http://localhost:9999/api-docs
